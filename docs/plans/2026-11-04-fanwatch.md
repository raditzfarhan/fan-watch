# FanWatch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A light native Windows app that, when opened, shows a sortable table of apps by CPU and memory, flags the most likely fan culprit straight away, and lets the owner end it.

**Architecture:** A pure `Core` layer (process reading, CPU maths, grouping, culprit scoring, Claude session lookup, protection rules), unit-tested with fake samples. A thin WinForms `MainForm` on top refreshes every 2 s. Process data comes from one `NtQuerySystemInformation(SystemProcessInformation)` call per refresh. That gives CPU time, start time, working set, parent PID and name for *every* process without opening handles, so there are no access-denied errors and it stays cheap.

**Tech Stack:** C# 13, .NET 10 (LTS), WinForms (`net10.0-windows`), xUnit, `System.Text.Json`. No third-party runtime packages.

**Spec:** `C:\laragon\www\claude\fanwatch\docs\2026-11-04-fanwatch-design.md`

## Global Constraints

- Own footprint: under 1% of total CPU while the window is open, about 60 MB RAM or less, nothing running when closed.
- Refresh every 2 seconds while the window is open.
- CPU percentages are % of the whole machine (all logical cores).
- No tray icon, no notifications, no background mode, no history across runs.
- Runs as a normal user (no elevation manifest).
- Protected (no End button): System, Idle, Registry, smss, csrss, wininit, winlogon, services, lsass, svchost, dwm, fontdrvhost, Memory Compression, MsMpEng, and FanWatch itself.
- Group confirmation copy: `End all {n} {Name} processes?`. Single process: `End {label}? Anything unsaved in it will be lost.` Claude: `End {label} and its {n} child processes? Anything unsaved in it will be lost.`
- Quiet message: `Nothing is working hard right now. Fan noise may be from charging or the laptop cooling down.`
- Not a git repo and the owner hasn't asked for one, so there are **no commit steps**. Each task ends with its tests passing instead.

## Review Focus

1. **PID reuse:** a session file or parent PID that points at a *different, newer* process with the same PID must not be attributed. Pinned by `ClaudeSessionsTests.IgnoresFileWhenProcStartMismatch` and `GrouperTests.ChildStartedBeforeParentIsNotAttributed`.
2. **Processes that exit between refreshes** (they vanished mid-sample in testing): history must drop them, End on a vanished process reports "already closed", and nothing throws. Pinned by `CpuHistoryTests.DropsExitedProcesses` and `ProcessKillerTests.AlreadyGoneIsReportedNotThrown`.
3. **The first seconds after opening:** CPU now / avg 60 s are null, yet a culprit must still be picked from CPU since start alone. Pinned by `CulpritScorerTests.PicksLongRunnerOnFirstRefresh`.
4. **Many-member groups** (svchost 95, Brave 42) must not win on summed CPU. Pinned by `CulpritScorerTests.GroupSizeDoesNotWin`.
5. **Malformed or missing session JSON**, or no sessions folder at all: falls back to plain `claude`. Pinned by `ClaudeSessionsTests.MalformedJsonFallsBack`.

### Task 2: Reading real processes and system stats

**Files:**
- Create: `src/FanWatch/Core/IProcessSource.cs`, `src/FanWatch/Core/SystemStats.cs`
- Test: `tests/FanWatch.Tests/NtProcessSourceTests.cs` (runs against the real machine)

**Interfaces:**
- Consumes: `ProcSample` (Task 1)
- Produces:
  - `interface IProcessSource { IReadOnlyList<ProcSample> Read(); TimeSpan IdleCpuTime { get; } }`. `IdleCpuTime` is the PID 0 CPU time from the last `Read`, summed over all cores.
  - `sealed class NtProcessSource : IProcessSource`. It calls `NtQuerySystemInformation(5 /*SystemProcessInformation*/)` with a buffer that grows on `STATUS_INFO_LENGTH_MISMATCH` and is reused between calls. It walks `SYSTEM_PROCESS_INFORMATION` via `NextEntryOffset` and reads `UniqueProcessId`, `InheritedFromUniqueProcessId`, `ImageName`, `CreateTime` (FILETIME → UTC), `UserTime + KernelTime`, and `WorkingSetSize`. PID 0 is named `Idle`, and PID 0 is excluded from `Read()`'s result. A name that ends in `.exe` has it stripped.
  - `sealed record SystemSnapshot(double CpuPercent, long RamUsedBytes, long RamTotalBytes, bool Charging, int? BatteryPercent)`
  - `static class SystemStats { SystemSnapshot Take(TimeSpan idleDelta, TimeSpan wall, int cores); }`. CPU = `100 - IntervalPercent(idleDelta, wall, cores)`. RAM comes from `GlobalMemoryStatusEx`. Battery comes from `SystemInformation.PowerStatus`; with no battery, `BatteryPercent` is null.

### Task 5: Grouping into rows

**Files:**
- Create: `src/FanWatch/Core/Row.cs`, `src/FanWatch/Core/Grouper.cs`
- Test: `tests/FanWatch.Tests/GrouperTests.cs`

**Interfaces:**
- Consumes: `ProcSample`, `CpuHistory`, `ClaudeSessions`, `Protection`, `CpuMath`
- Produces:
  - `enum RowKind { Single, Group, ClaudeSession }`
  - `sealed class Row { string Label; RowKind Kind; IReadOnlyList<ProcSample> Members; IReadOnlyList<Row> Children; double? CpuNow; double? Avg60; double SinceStart; TimeSpan CpuTotal; long Memory; bool Protected; string? Hint; double Score; CulpritMark Mark; }`. `CulpritMark { None, Primary, Secondary }` is set by Task 6.
  - `static class Grouper { IReadOnlyList<Row> Build(IReadOnlyList<ProcSample> samples, CpuHistory history, ClaudeSessions claude, DateTime nowUtc, int cores); }`

Rules:
- Every process named `claude` gets its own `ClaudeSession` row, labelled `claude ({project})` or `claude`. Its `Members` are itself plus all descendants, found by walking `ParentPid`. A child only counts if `child.StartUtc >= parent.StartUtc`, and a nested claude is not absorbed. Descendants claimed by a claude row are removed from name grouping. Children are one `Single` row per member.
- Remaining processes are grouped by `Name` (case-insensitive). A count of 1 gives a `Single` row labelled `Name`. More than 1 gives a `Group` row labelled `Name ({n})`, with `Single` children.
- Metrics on multi-member rows are sums of members. `CpuNow` / `Avg60` are null if every member's value is null; otherwise nulls count as 0. `SinceStart` per member = `SinceStartPercent(cpu, now - start, cores)`. `Protected` = any member is protected. `Hint` = `HintFor(Name)`.

### Task 6: Culprit scoring

**Files:**
- Create: `src/FanWatch/Core/CulpritScorer.cs`
- Test: `tests/FanWatch.Tests/CulpritScorerTests.cs`

**Interfaces:**
- Consumes: `Row` (Task 5)
- Produces: `static class CulpritScorer { const double QuietOverall = 15, QuietProcess = 3; Row? Apply(IReadOnlyList<Row> rows, double overallCpu, DateTime nowUtc); }`. It sets `Score` and `Mark` on rows and returns the primary culprit row, or null when quiet.

Algorithm (my call, within the spec's constraints). Score *units* are each `ClaudeSession` row (its tree summed) and each individual process anywhere else (the `Single` rows and the children of `Group` rows), never a whole `Group`:

```
ageWeight = min(1, age / 10 minutes)          // age of the unit's root process
score     = max(SinceStart * ageWeight, Avg60 ?? 0)
```
- Quiet: if `overallCpu < 15` and the top score is `< 3`, mark nothing and return null.
- Primary = the top-scoring unit, marked `Primary`. If it's inside a `Group`, the group row is also marked `Primary`, and the UI auto-expands it.
- If the primary is `Protected`, the top-scoring unprotected unit with score ≥ 3 is marked `Secondary`.

### Task 7: Ending processes

**Files:**
- Create: `src/FanWatch/Core/ProcessKiller.cs`
- Test: `tests/FanWatch.Tests/ProcessKillerTests.cs`

**Interfaces:**
- Consumes: `Row`, `ProcSample`
- Produces:
  - `sealed record KillResult(int Ended, int AlreadyGone, int Failed, string Message)`
  - `sealed class ProcessKiller { Task<KillResult> EndAsync(Row row, TimeSpan closeGrace /* 3 s */); string ConfirmText(Row row); }`

Rules:
- Order: descendants deepest-first, then the root.
- For each member, open `Process.GetProcessById`. If its `StartTime` (UTC) doesn't match `StartUtc`, or it no longer exists, count it as `AlreadyGone`. If it has a `MainWindowHandle != 0`, call `CloseMainWindow()` and wait up to `closeGrace`. Then `Kill()` if it's still alive.
- `Win32Exception` / `InvalidOperationException` count as `Failed` and are never thrown.
- `Message` examples: `Ended 3 processes.`, `Could not end 1 process (access denied).`, `Already closed.`
- `ConfirmText` uses the Global Constraints copy, where Claude `{n}` = members − 1.

- [ ] **Step 1: Write failing tests:**

  - `AlreadyGoneIsReportedNotThrown`: a sample with an unused PID. Expect `AlreadyGone == 1`.
  - `PidReuseNotKilled`: the real PID of the spawned ping, but with `StartUtc` set 1 h earlier. Expect `AlreadyGone == 1` and ping still alive (kill it in cleanup).
  - `ConfirmTextClaude`: expect `End claude (my-office) and its 3 child processes? Anything unsaved in it will be lost.`
  - `ConfirmTextGroup`: expect `End all 42 brave processes?`
